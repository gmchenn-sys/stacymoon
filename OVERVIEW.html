🎯 特色功能亮点

📋 今日小任务引擎
根据打卡症状+档案运动习惯，从任务池匹配定制每日任务（60+条任务库，覆盖潮热/出汗/睡眠/情绪/关节/脑雾/少运动/通用）。日期做种子保证每天不重样。Health & Her 同款逻辑。
🤖 动态开场语
3级优先级：昨天打卡数据分析 → 档案症状匹配 → 随机固定文案。"昨晚睡得不太好？今天感觉怎么样"——每次打开对话页都不一样。
📊 就医报告自动生成
聚合档案+打卡+对话三源数据。BMI 自动计算、对话关键词匹配 top5、30天打卡趋势、睡眠最差一周自动定位。白底卡片仿正式文件，复制全文即粘贴给医生。
🔔 飞书双向通知
每次对话推送结构化卡片给女儿：妈妈说了什么 + 今日心情/睡眠/症状。周报一键推送（紫色模板）。女儿不用装 App，飞书即收。
🎤 讯飞双引擎语音
STT: AudioContext → 16kHz 重采样 → 讯飞 iAT WebSocket 实时听写
TTS: /api/tts CF 代理 → 讯飞 TTS WebSocket → 分段音频拼接修复
📈 打卡趋势可视化
SVG 睡眠折线图（30天）、情绪色块矩阵、高频症状 TOP3 排名。纯 CSS/SVG 实现，无第三方图表库。
📱 PWA 全屏应用
apple-mobile-web-app-capable + 安全区域适配。iPhone 添加到主屏幕后无缝全屏体验，底部5 tab 导航栏贯穿全站。
⏰ 用药提醒系统
添加次数+时间选择器，Notification API 浏览器推送。每次页面加载时自动注册当天剩余提醒。预填档案 medication 字段。
