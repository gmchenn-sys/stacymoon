# T-014：ESP32-S3 连 WiFi + 调 Stacy 后端（打印回复）

## 目标
板子连上 WiFi，POST 一条消息到 Stacy Agent 主入口，解析 SSE，把组装好的回复文本 + intent 打到串口。证明「设备 ↔ Stacy 后端」链路通。第二个里程碑，先不接 LED/喇叭。

## 前置：先 curl 探活（别照文档瞎写）
先从 Mac 命令行确认后端真活着、抓一份真实 SSE 返回，再照真实结构写固件：
```
curl -N -sS -X POST https://stacymoon.online/chat/stream \
  -H 'Content-Type: application/json' \
  -d '{"message":"你好","user_id":"hw_demo_001","reply_mode":"text","channel":"text","stacy_profile":{"name":"测试","age":50}}'
```
- 若返回 SSE（`data: {"type":"thinking"}` → `token` → `done`）→ 记下真实的 `done.response` 结构，按它写解析。
- 若报 4xx/5xx 或超时/连不上 → **立刻汇报**（贴 curl 输出），不要硬写固件。可能后端没起或 user_id 需真实邀请码——由 architect 定夺。

## 环境
- FQBN `esp32:esp32:esp32s3`；串口 `/dev/cu.usbmodem5C381910391`
- WiFi：SSID/密码见下方 secrets（architect 私发，写进 gitignore 文件，**绝不进 git**）
- 端点：`https://stacymoon.online/chat/stream`（HTTPS，用 `WiFiClientSecure` + `setInsecure()` 跳过证书校验即可）

## 要做
1. `.gitignore` 加 `firmware/*/secrets.h`。
2. `secrets.h`：`#define WIFI_SSID ...` / `#define WIFI_PASS ...` / `#define STACY_USER_ID "hw_demo_001"`（值 architect 私发）。
3. `stacy_chat.ino`：
   - 连 WiFi，串口打印「连接中…」→ 成功后打印拿到的 IP。
   - 连上后 POST 上面的 JSON 到 `/chat/stream`，HTTPS。
   - 读 SSE：逐行读 `data: {...}`，遇 `type:"token"` 累加 `content`，遇 `type:"done"` 取 `response` 和 `intent`。用 ArduinoJson 解析（`arduino-cli lib install ArduinoJson`）。
   - 串口打印：HTTP 状态码、逐个 token（可选）、最终 `【回复】<response>` 和 `【intent】<intent>`。
4. 编译 + 烧录 + 串口抓取，确认能看到「WiFi 连上（有 IP）→ 200 → 打印出 Stacy 的中文回复」。
