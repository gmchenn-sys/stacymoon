# T-021 · 语音会话提示改系统条 + 气泡不被遮挡 + 按真实采样率播放（P0）

来源：Slack `#app-develop-stuff` Christine 2026-07-26 凌晨 5:29 的整改单（voice 侧已改完并部署 commit `991aa8a`，现在轮到前端配合）。JM 真机反馈：对话呈现不完整、会话提示混进聊天气泡、语音播放卡顿。

## 目标

三件事，全部在 `app.js` + `style.css` + `index.html`：

### 1. 会话提示改「系统状态条」，不得冒充 Stacy 回复

现在这四处用 `appendBubble('ai', ...)` 生成了带 🌙 头像的 assistant 气泡，用户会误以为是月亮在说话：

- `app.js:751` `'另一个页面正在语音中，先关掉那边再试试 🌙'`
- `app.js:763` `'好的，请说话 🌙'`
- `app.js:842` `'语音连接失败，请稍后再试 🌙'`
- `app.js:896` `'好的，下次再聊 🌙'`

要求：
- 新增 `appendSystemNote(text)`（放在 `appendBubble` 附近，约 app.js:246 之后），生成**居中的细字系统条**：无 🌙 头像、无气泡背景色，样式类如 `.system-note`（在 style.css 里加，配色用现有 `--muted` / `--border` 变量，字号 `0.8rem` 左右，居中，上下留 4px）。
- 上述四处改调 `appendSystemNote`，**去掉文案里的 🌙**（它不是月亮说的话）。
- 追加后同样要滚到底（复用 `box.scrollTop = box.scrollHeight`）。
- **不得写进聊天历史**：`appendBubble` 本身不写 localStorage，`appendSystemNote` 同样只操作 DOM 即可；不要碰 `vtCompleteTurn` / `stacy_logs` 落库逻辑。

### 2. 最后一条气泡不被底栏遮挡

实测（stacymoon.pages.dev，桌面视口 1041px 高）：`.input-area` 高 **97px**，底部导航 **60px**，合计遮挡 **157px**；而 `index.html:112` 里 `.chat-box{padding-bottom:140px !important}` —— **少 17px**，所以最后一条气泡被切掉。大字号（`stacy_font_scale=1.3`）时输入栏更高，差得更多。

要求：
- 把 `.chat-box` 的 `padding-bottom` 改成**跟随实际高度**，不要再写死。推荐做法：input-area 用 CSS 变量或 JS 在 `resize`/字号变更时测量 `.input-area` 实际高度写进 `--input-area-h`，`.chat-box` 用 `calc(var(--input-area-h, 100px) + 60px + 16px)`。做不了动态就至少改成 `180px` 并在 1.3 字号下手测不遮挡。
- **token / done 之后自动滚到底**：流式回复过程中气泡在长高，确保结束时最后一条完整可见（检查 app.js 里流式渲染的收尾处有没有 `scrollTop = scrollHeight`，没有就补）。

### 3. 接 `/voice/session` 的 `audio_out_sample_rate`

现在 `BotAudioPlayer` 的 `this._sourceRate = 44100`（`app.js:546`）是**硬编码**，而 MiniMax TTS 实际采样率不一定是 44100 —— 这正是 `underrun` / 播放断续卡顿的根因（按错误采样率重采样，消耗速度和供流速度对不上）。

要求：
- `startVoiceCall` 里解析响应时一并取出：`const { ws_url, audio_out_sample_rate } = await res.json();`
- 把它传给 `BotAudioPlayer`（构造函数加可选参数，或加 `setSourceRate(rate)`），替代硬编码 44100；**字段缺失时回退 44100**（Christine 那边刚上线，容错要有）。
- 注意 `init()` 用 `this._ready` 缓存了 AudioWorkletNode，`processorOptions.sourceRate` 是**创建时**传入的 —— 采样率必须在 `init()` 之前设定好，或变更时销毁重建 node，否则改了不生效。
- `_enqueuePcm` 里算时长的 `this._sourceRate` 会自动跟着对。
- 打一条 `console.log('[VOICE] audio_out_sample_rate =', rate)` 方便真机核对。

### 4. bump 版本号（CLAUDE.md 硬性要求）

`index.html:318` `app.js?v=18` → `?v=19`（改了 app.js 必须同步 +1，否则 Cloudflare/手机继续加载旧 JS）。`api.js` 没改就别动。
