# T-013：ESP32-S3 烧录链路验证（板载灯闪烁）

## 目标
写一个最小固件，编译 + 烧录进已连接的 ESP32-S3 开发板，证明整条「写码 → 编译 → 烧录 → 板子运行」链路通。硬件第一个里程碑，其余先都不做。

## 环境（已确认）
- arduino-cli 已装，`esp32:esp32 3.3.10` 已装
- 板子 FQBN：`esp32:esp32:esp32s3`
- 串口：`/dev/cu.usbmodem5C381910391`
- 项目根：`/Users/gmc/Desktop/stacymoon`

## 涉及文件（只准动这些）
- 新建 `firmware/blink/blink.ino`

## 要做
1. `firmware/blink/blink.ino`：
   - 每 500ms 翻转 LED，并每次往 Serial 打印递增行 `blink N`（波特率 115200）。Serial 输出是验收关键——即使板载灯类型不对也能证明链路通。
   - ESP32-S3 板载灯多为 WS2812 RGB（常在 GPIO48），非普通 GPIO 灯。用 core 3.x 自带 `rgbLedWrite()`/`neopixelWrite()` 驱动 RGB，同时也 `digitalWrite(GPIO2)` 做双保险。
2. 编译：`arduino-cli compile --fqbn esp32:esp32:esp32s3 firmware/blink` → exit 0
3. 烧录：`arduino-cli upload -p /dev/cu.usbmodem5C381910391 --fqbn esp32:esp32:esp32s3 firmware/blink` → exit 0
   - 若报端口/复位错误：ESP32-S3 有时需手动进下载模式（按住 BOOT → 按 RST → 松开）。把报错和已试办法一并汇报，别瞎试超 3 次。
4. 串口验证：`arduino-cli monitor -p /dev/cu.usbmodem5C381910391 -c baudrate=115200` 抓 3–5 秒，确认 `blink N` 递增。

## 验收命令（三样都要过）
- `arduino-cli compile --fqbn esp32:esp32:esp32s3 firmware/blink` → exit 0
- `arduino-cli upload -p /dev/cu.usbmodem5C381910391 --fqbn esp32:esp32:esp32s3 firmware/blink` → exit 0
- 串口抓到 `blink N` 递增
