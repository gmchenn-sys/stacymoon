# T-008 · 打卡表单移植到「记录」页（T-007 IA 改版的配套，P0）

> status: done

## 背景
T-007 把 home.html 重定向到聊天页（IA 会议决定：无首页 Tab）。但打卡表单原本在 home.html 上，重定向后用户没有入口打卡了。「记录」页（history.html）现在只有打卡列表，没有表单。聊天页 Dashboard 的「去打卡」按钮链接到 history.html，等着这张卡接住。

## 目标
history.html 顶部加当日打卡表单；今天已打卡则显示摘要。顺带落实 Slack 频道 F1/F3 两条 UX 要求。

## 实现要求
1. 从 git 历史里 home.html 的实现移植（`git show eec360a:home.html` 可看 T-002 改造后的版本）：
   - 心情选择（emoji 按钮）、睡眠 1–5、症状多选、备注输入、提交按钮；
   - 提交走 **store.js 的 `saveDailyLog(data)`**（history.html 已引入 store.js 则复用，未引入则加 `<script src="store.js">`，注意放在使用之前）；
   - 提交后刷新表单区（变摘要）和下方打卡列表。
2. 今天已有记录（按 date 匹配 `getDailyLogs()` 结果）→ 显示摘要卡（心情·睡眠·症状·备注），不显示表单。
3. **F1 量表同向**：心情按钮从"差→好"排列（😢低落 😤烦躁 🥱疲惫 😌平静 😊不错），与睡眠 1差–5好 方向一致。emoji 的 value 保持原字符（数据兼容），只改展示顺序。
4. **F3 大字号不溢出**：备注输入框宽度用 %/flex，`font-size` 用 rem；在 `stacy_font_scale=1.3` 时手测不溢出（把 localStorage 设 1.3 刷新看）。
5. 样式贴合 history.html 现有暗色卡片风格（--surface/--border/--radius 变量）。
