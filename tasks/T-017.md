# T-017：外接可编程 RGB 灯（GPIO4）自检 + 情绪色镜像

## 背景
用户接了一颗**单数据线可编程 RGB 灯**（WS2812/SK6812 类）到板子：`-`→GND、中→3V3、`S`→**GPIO4**。上电默认亮红（未收数据）。需固件从 GPIO4 用 `rgbLedWrite` 驱动它。

## 目标
改 `firmware/stacy_chat/stacy_chat.ino`：
1. 新增外接灯常量 `RGB_EXT_PIN = 4`。
2. **开机自检**：setup 里先让外接灯跑 红→绿→蓝→灭（各 ~600ms），串口打印 `EXT LED test: red / green / blue`。这步用来确认接线与可控性。
3. **情绪色镜像**：`setLedByIntent()` 里，除了驱动板载 GPIO48，**同一颜色也写到外接 GPIO4**（`rgbLedWrite(RGB_EXT_PIN, r,g,b)`）。过程状态色（黄/蓝）也镜像到外接灯。
4. 保留 T-016 的轮播 + WiFi + chat 全部逻辑不变。
