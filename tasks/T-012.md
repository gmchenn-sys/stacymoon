# T-012: 修复 index↔home 跳转死循环（线上屏闪进不去，P0）

## 背景

T-007 IA 改版把首页并入聊天页，home.html 开头改成了无条件 `location.replace('index.html')`（保留是为了兼容旧桌面快捷方式）。但 index.html 邀请码逻辑里"回访老用户 → 先去首页"的旧分支没删，导致：

- index.html:344 — 已有邀请码+档案、且无 `sessionStorage.from_home` 标记 → `replace('home.html')`
- home.html:6 — 无条件 `replace('index.html')`

两页互相 replace 无限循环，**所有已建档老用户打开站点就屏闪，完全进不去**。线上 stacymoon.pages.dev 已复现确认。

## 目标

老用户打开 index.html 直接留在聊天页正常使用；home.html 保留跳回 index.html 的兼容重定向。

## 改动点

**index.html（核心修复）**
1. 约 339–346 行：删除 `from_home` 判断分支，回访用户（有邀请码+档案）直接 `overlay.style.display = 'none'`，不再跳 home.html。顺手 `sessionStorage.removeItem('from_home')` 清残留。
2. 约 403–407 行：邀请码验证成功后，有档案时不再 `replace('home.html')`（overlay 在 401 行已隐藏，直接留在聊天页）；无档案跳 onboarding.html 的分支保留。

**顺手清理（把指向 home.html 的入口改成 index.html，避免多一次重定向跳变）**
3. onboarding.html:115 — `replace('home.html')` → `replace('index.html')`
4. onboarding.html:353 — `location.href = 'home.html'` → `'index.html'`
5. profile.html:119 返回按钮、profile.html:319 保存后跳转 — `home.html` → `index.html`
6. reminder.html:126 返回按钮 — `home.html` → `index.html`

**注意**：从 onboarding/profile 跳到 index.html 时不需要设 `from_home`（修复后 index 不再检查它）。

## 禁区

- **不要动 home.html**（它的 redirect 是 Android 旧快捷方式的兼容层，保留原样）
- 不要动 app.js / api.js（不涉及，就不用 bump ?v=N）
- 不要动 dashboard.js / store.js / server.js 里的注释性引用
- 禁止 git add -A，只 add：index.html onboarding.html profile.html reminder.html tasks/T-012.md

## 验收命令

```bash
# 1. index/onboarding/profile/reminder 不再有任何指向 home.html 的跳转
grep -n "home\.html" index.html onboarding.html profile.html reminder.html; test $? -eq 1 && echo PASS-1

# 2. index.html 不再引用 from_home（残留清理语句除外，最多 1 处 removeItem）
test "$(grep -c "from_home" index.html)" -le 1 && echo PASS-2

# 3. home.html 兼容重定向保持原样
grep -n "location.replace('index.html')" home.html && echo PASS-3
```
