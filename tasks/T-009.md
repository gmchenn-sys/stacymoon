# T-009 · F10 隐私：亲属通知默认不推，用户主动开启（P1，Slack 频道要求）

> status: done

## 背景
notify.js 现在每轮对话都自动推飞书给女儿（app.js 每轮调 `notifyDaughter`），聊天页脚注也写着"每次对话，关心你的人都会收到通知"。IA 会议 F10：隐私默认**不推**关心人，仅用户主动分享。

## 实现要求
1. `notify.js`：`notifyDaughter` 入口加开关判断——`localStorage.stacy_share_daughter !== '1'` 时直接 return，不发任何请求。
2. `profile.html`：加"分享给关心的人"开关行（勾选写 `stacy_share_daughter`='1'/移除），默认关。样式贴现有表单风格。
3. `index.html`：脚注文案改为中性："想让家人收到你的动态？在「我的」里开启分享"，且仅在开关未开时显示；开了显示原文案。一行 JS 判断即可。

## 涉及文件
- `notify.js`、`profile.html`、`index.html`

## 禁区
- 不动 app.js / 周报的手动推送按钮（weekly.html 的主动推送是用户主动行为，保留）
- 禁止 git add -A

## 验收标准
```bash
grep -n 'stacy_share_daughter' notify.js profile.html index.html
```
手测：默认状态下发一条消息，Network 无飞书 webhook 请求；开关打开后恢复推送。

## 完成动作
`git add notify.js profile.html index.html tasks/ && git commit -m "T-009: 亲属通知默认不推(F10)"`，agmsg 报 architect。
