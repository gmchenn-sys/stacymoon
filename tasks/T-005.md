# T-005 · 聊天→打卡通道（Agent 写入「记录」第一步，P1）

> status: done

## 背景
Agent-First 目标：用户说话 → Agent 理解 → 写入记录。现状聊天内容和打卡完全隔离——用户在聊天里说"昨晚又热醒了"，打卡里什么都不会发生。本卡打通第一条通道：**确认后记**（不自动写，用户点一下才落库）。

## 目标
文字聊天每轮结束后，若消息含健康信号且今天还没打卡，在聊天流里插入一个建议卡片："帮你把今天记一笔？"，一键写入 daily_logs。

## 实现要求
1. `app.js` 新增信号检测（纯前端关键词 + intent 辅助）：
   - 关键词→symptom key 映射：潮热→hot_flash；出汗/盗汗/热醒→night_sweat；睡不好/失眠/没睡/热醒→poor_sleep；烦/情绪/心情差/想哭→mood_swing；关节/腰疼/膝盖→joint_pain；记性/脑雾/忘→brain_fog。
   - 触发条件：**userMessage 命中至少一个关键词** 且 `getLastStreamMeta()` 的 intent ∈ {emotional_support, health_knowledge}（intent 为 null 时仅靠关键词也可触发）且今天 stacy_daily_logs 里没有当天记录。
2. 触发后在聊天流 append 一个建议气泡（样式参考现有 bubble，加一个按钮）：文案"要不要把今天记一笔？（症状：潮热、睡不好）"+「记一笔」按钮 +「不用」按钮。
   - 点「记一笔」→ 调 store.js 的 `saveDailyLog({mood:'', sleep_score:0, symptoms:[命中的keys], note: userMessage.slice(0,40)})`，气泡变为"已帮你记下 ✓"；
   - 点「不用」→ 气泡消失，当天不再提示（localStorage `stacy_checkin_prompt_dismissed` 存当天日期）。
3. `index.html` 引入 `<script src="store.js">`（在 app.js 之前）。
4. 每天最多提示一次（记过/点过不用都不再出）。

## 涉及文件
- `app.js`、`index.html`

## 禁区
- **绝不自动落库**——必须用户点按钮
- 不动 saveLog（聊天记录落库）逻辑
- 不动语音链路
- 建议气泡不写入 stacy_logs（它不是对话内容）

## 验收标准
```bash
grep -n 'saveDailyLog' app.js
grep -n 'store.js' index.html
grep -n 'stacy_checkin_prompt_dismissed' app.js
```
浏览器手测：无当日打卡时发"昨晚又热醒了，一身汗"→ 回复后出现建议气泡，点「记一笔」→ localStorage stacy_daily_logs 出现当天记录（symptoms 含 night_sweat/poor_sleep）；再发同类消息不再提示。
