# T-015：情绪灯 — 板载 WS2812 按 intent 变色

## 目标
扩展 `firmware/stacy_chat/stacy_chat.ino`：一次后端对话拿到 `intent` 后，让**板载 WS2812 RGB 灯（GPIO48，`rgbLedWrite`）**按 intent 亮对应颜色。零外接、纯软件。证明「情绪 → 变色」链路。

## intent → 颜色映射（RGB，亮度压低护眼）
| intent | 颜色 | rgbLedWrite 参数(建议) |
|---|---|---|
| `general` | 绿 | `(0, 60, 0)` |
| `health_knowledge` | 青蓝 | `(0, 40, 60)` |
| `emotional_support` | 暖橙 | `(70, 25, 0)` |
| `crisis` | 红（闪烁 3 次再常亮） | `(90, 0, 0)` |
| 未知/空 | 暗白 | `(20, 20, 20)` |

**过程状态色（可选但建议，让 demo 有"活着"的反馈）**：
- 开机/连 WiFi 中：黄色慢闪 `(40, 40, 0)`
- WiFi 失败：红色常亮
- 等后端回复中：蓝色 `(0, 0, 50)`
- 拿到回复：切到上表 intent 色并保持

## 涉及文件（只准改这个）
- 改 `firmware/stacy_chat/stacy_chat.ino`（在已有 WiFi+chat 基础上加 LED，**不得破坏** WiFi/chat/SSE 逻辑）

## 要做
1. 加 `setLedByIntent(const String& intent)`：按上表 `rgbLedWrite(48, ...)`；crisis 先闪 3 次。
2. `setup()` 里：开机点黄慢闪→连上 WiFi 后（chatOnce 前）点蓝；`chatOnce()` 拿到 `finalIntent` 后调 `setLedByIntent(finalIntent)`。
3. 串口每次打印映射结果，例如 `LED intent=general -> (0,60,0) green`（验收要靠这行确认逻辑跑到）。
4. 保持 T-014 的所有串口输出不变（WiFi OK/HTTP 200/【回复】/chatOnce OK）。
