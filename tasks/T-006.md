# T-006 · 首页今日摘要 Agent 化（P1）

## 背景
首页"小任务"目前是本地 TASK_BANK 按日期取模，与 Agent 无关。Agent-First 目标是首页成为 Agent 输出层。weekly.html 的 AI 周报小结已有先例（合成 prompt + 真实 user_id 调 Agent）。本卡把首页加一条 Agent 生成的"今日关心"。

## 目标
home.html 顶部（打卡卡片上方）新增"Stacy 今日关心"卡片：基于今天的打卡 + 最近聊天，由 Agent 生成一句话关心/建议。**每天只调一次**，缓存当天结果。

## 实现要求
1. `home.html` 新增卡片区块（样式与现有 card 一致），初始隐藏。
2. 生成逻辑：
   - 缓存：localStorage `stacy_daily_brief` 存 `{date, text}`，当天已有则直接显示，**不再调 Agent**；
   - 无缓存时组装 prompt：今日打卡（心情/睡眠/症状，来自 getTodayLog）+ 最近 1 条聊天摘要（stacy_logs 最后一条的 userMessage 前 30 字），模板："用户今日状态：…。请用一句话（30字以内）温柔地关心她或给一个当天可执行的小建议，直接说内容。"；
   - 调用走 api.js 的 `askStacyStream`（T-003 已收敛，不要再用 /api/chat），收完整回复后显示并写缓存；
   - 完全没有今日数据（没打卡且无聊天）时不调 Agent、不显示卡片；
   - 请求失败静默隐藏卡片（不能报错打断首页）。
3. `home.html` 需引入 `api.js`（若未引入）。注意 api.js 顶部有 conversationHistory 等全局量，确认与 home.html 现有全局不冲突。
4. 现有 TASK_BANK 小任务卡**保留不动**（作为离线兜底，两卡并存）。

## 涉及文件
- `home.html`（如需微调导出，允许小改 `api.js`，其他不动）

## 禁区
- 每天最多一次 Agent 调用（缓存必须生效）
- 不动 TASK_BANK / 打卡 / 周报入口逻辑
- 失败必须静默，不能影响首页其他区块渲染

## 验收标准
```bash
grep -n 'stacy_daily_brief' home.html
grep -n 'askStacyStream' home.html
```
浏览器手测：有今日打卡时打开 home.html → "今日关心"卡片出现 Agent 文案；刷新页面 → 文案不变且 Network 无新 /chat/stream 请求（缓存生效）；清掉打卡和聊天记录 → 卡片不显示。
