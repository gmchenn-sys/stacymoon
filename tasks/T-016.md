# T-016：情绪色轮播 — 让灯真的变起来

## 目标
改 `firmware/stacy_chat/stacy_chat.ino`：不再只发一次"你好"，而是在 `loop()` 里**轮流发几句不同情绪的话**给后端，每句拿到 `intent` 后点对应灯色，间隔停留让眼睛看清。板子灯会**绿 → 橙 → 青**循环变色，证明"情绪真的驱动灯"。纯软件、零接线。

## 轮播消息（贴老人健康陪伴场景，尽量触发不同 intent）
按数组轮流发送，循环往复：
1. `"闺女今天给我打电话了，我们聊得挺开心"` — 预期 general → 🟢绿
2. `"我这两天心里特别烦，晚上老睡不着，总觉得孤单难受"` — 预期 emotional_support → 🟠橙
3. `"医生说我血压有点偏高，平时饮食上要注意些什么？"` — 预期 health_knowledge → 🔵青蓝

> 注：intent 由后端判定，**实际可能和预期不完全一致**——那是后端行为不是固件 bug。验收只要求"多轮里出现 ≥2 种不同 intent/灯色"。

## 要做
1. 把硬编码的单条 message 改成上面 3 条的数组，`loop()` 里每轮取下一条（`i = (i+1) % 3`）发送。
2. 每轮：发送前点蓝(等回复中) → 拿到 intent 调 `setLedByIntent()` → **停留 12 秒**保持该色让人看清 → 进入下一轮。
3. 串口每轮打印：第几条、发的消息、`intent`、灯色（保留 `LED intent=... -> (...)` 行）。
4. 复用已有 WiFi 连接（WiFi 在 setup 连一次即可，别每轮重连 WiFi；但每轮可新建 TLS 连接发请求）。
