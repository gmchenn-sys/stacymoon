# T-003 · 文字聊天收敛到 /chat/stream + stacy_profile 全量透传

## 背景
契约 §10 前端清单未完成项：`api.js` 的 `askStacy()` 仍走 legacy 同步 `/api/chat`（Cloudflare 代理 → /chat）；`stacy_profile` 只传 name/age 两个字段，契约 §6.1 定义了完整建档结构，路线图 P1 要求 Agent 接收 symptoms/exercise/medication——前端先把字段传全。

## 目标
1. 全站文字聊天只走 `askStacyStream()`（`POST https://stacymoon.online/chat/stream`），删除或废弃 `askStacy()` 的 legacy 路径。
2. `stacy_profile` 按契约 §6.1 全量透传。

## 实现要求
1. `api.js`：
   - 抽一个 `buildStacyProfile()`：返回 `{name, age(Number), height, weight, period_status, symptoms, exercise, exercise_type, diet, medication}`，undefined 字段省略。
   - `askStacyStream` 请求体改用 `buildStacyProfile()`。
   - 检查 `askStacy()` 的调用方（grep 全仓库）：若 app.js/weekly.html 还在用，改成走 stream 版（weekly 的 AI 总结可以用 askStacyStream 收完整回复，不需要逐句回调）。调用方清零后删除 `askStacy()`。
2. `weekly.html:383` 的 `/api/chat` 调用同步迁移。
3. 保持 SSE 解析逻辑（thinking → evidence → token → done）不动；`lastStreamMeta` 机制不动。

## 涉及文件
- `api.js`、`app.js`（如有调用）、`weekly.html`

## 禁区
- 不动语音链路（worklet.js / 语音 WS）
- 不动 saveLog 写库字段
- server.js 的 /api/chat 代理可以保留（别的端可能在用），只是前端不再调用
