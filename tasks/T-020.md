# T-020：外接双色 LED 接入情绪灯

## 背景
外接"全彩灯"实为**双色 LED**（红+黄绿两灯珠，非 WS2812）。rgbLedWrite/NeoPixel 均无效——它不吃数据。改为 digital 直驱两脚。
- 接线：`-`→GND、中间→3V3？（实为红灯珠一端）、`S`→GPIO4、另一端→GPIO5。EXT_RED=GPIO4，EXT_GREEN=GPIO5。

## 改动
`firmware/stacy_chat/stacy_chat.ino`：加 `extLed(redOn,greenOn)` digital 直驱；在 setLedByIntent/showcase/WiFi 连接处镜像情绪色。
- general→绿珠 / health+emotional→红+绿(橙) / crisis→红闪 / 未知→灭。
- 板载 WS2812（GPIO48，红蓝珠疑似faulty仅绿可见）逻辑保留不动。

## 验证（2026-07-22）
- compile/upload exit 0；串口 SHOWCASE 四行 + WiFi OK + HTTP 200 + LED intent 轮播正常。
- 物理：外接双色灯随 intent 在 黄绿/黄橙/红 间切换（用户确认"黄红交替"）。
